# Slot
This is a shitpost slot machine which we made during a liveshare session :D

**Get Started**
1. Open up devtools in the browser and navigate to the network tab.
2. Start typing in a channel on discord, you will see a typing request.
4. Copy the `authorization` token under `Request headers`
5. Paste it in the python file
6. Copy channel_id from the url, channels/`{channel id}`.
7. Paste it in the python file
8. Now you can run the ./spin command! (ᴗᵔᴥᵔ)
